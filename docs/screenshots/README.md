# Product screenshots

Sanitized product screenshots for the public beta should be stored here.

Capture at least:

1. The **Semantic Table** ribbon tab.
2. The **Semantic Table Fields** pane attached to a connected table.
3. The connection dialog showing placeholder values only.
4. A filtered result using synthetic or public sample data.

Before committing an image, inspect the entire capture for tenant names, workspace names, semantic-model names, usernames, file paths, workbook content, IDs, and connection details. Use PNG format and descriptive lowercase filenames such as `fields-pane.png`.
